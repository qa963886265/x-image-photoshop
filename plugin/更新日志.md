# 更新日志

## v1.10.3 · 2026-09-14

- 修复拖动参考图后，生成前主参考图被强制移回第一张的问题。
- 现在参考图的显示顺序就是实际上传顺序；精确回填仍使用独立保存的选区快照。
- 拖动后提示词中的 @图片编号会继续按图片 ID 正确对应。

## v1.10.2 · 2026-09-10

- 新增 Image 2.5 Flare（gpt-image-2.5-flare），支持 1K、2K、4K 和官网公开的 13 种比例。
- 原 Image 2.5 显示为 Image 2.5 Subrt，便于区分两个版本；Flare 单独读取实时价格。
- 修复切换模型后复用 4K 历史任务时，分辨率可能被重置的问题。
- 保留当前模型选择；需要使用新模型时，在模型渠道菜单中选择 Image 2.5 Flare。

## v1.10.1 · 2026-09-10

- 修复服务端明确生成失败时，被误报为“图片已返回，但本地处理失败”的问题。
- 父任务失败而子任务仍未确认结果时，继续保留历史找回机会，避免过早结束。
- 通知栏可悬停查看完整提示和服务端失败原因。
- 保持接口文档规定的模型、尺寸和分辨率；服务端失败不会触发自动付费重试。

此补丁修复插件的失败状态显示与找回逻辑。2K 请求保持官方文档规定的像素尺寸；上游渠道生成失败仍由服务端处理，退款以服务端账单为准。
