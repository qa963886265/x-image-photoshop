# 即杏智绘 v1.10.2

即杏智绘是用于 Photoshop 快速修图的插件，支持局部替换、参考图生成和结果精确放回选区。生成前需要至少一张参考图。

## 主要功能

- 从 Photoshop 选区、所选图层或电脑本地添加参考图，最多 6 张，单行紧凑排列。拖动可调整顺序，点击可向提示词中插入图片引用。
- 参考图预览铺满方框；提交生成时仍使用原图，不会按预览框裁切原始素材。
- 顶部保留图像编辑、词库和设置三个菜单；模特换装入口暂时隐藏。
- 可选 Image 2.5 Subrt、Image 2.5 Flare、Image 2、Gemini Flash、Gemini Pro 渠道，以及自动匹配、常用比例和 1K、2K、4K 分辨率。实际规格和费用以接口支持情况为准。
- 每个任务生成 1～4 张，同时最多运行 8 个任务，接口请求也最多并发 8 个。
- 生成历史最多保存 50 张结果，每页 4 个位置；运行中的任务也能翻页查看。结果提供复制提示词、复用任务和保存图片操作。
- 结果可作为智能对象插入 Photoshop；局部修图使用原选区蒙版和羽化范围控制衔接。
- 设置页的默认参数只保留羽化范围；账户和消费保护设置仍可使用。

## 快速使用

1. 在 Photoshop 中选中需要修改的区域，点击参考图区的“＋”，选择从选区获取；也可从图层或本地添加。
2. 输入需要替换的内容，以及要保留的人物、光线、构图等要求。点击参考图可在光标处插入引用。
3. 选择模型、分辨率、比例和生成数量，点击运行，或按 `Ctrl+Enter`。
4. 生成后选择结果并插入图层。需要精确放回时，使用任务保存的原选区位置和蒙版。
5. 需要继续调整同一任务时使用“复用”；“复制”复制提示词，“保存”导出图片。

自动匹配会参考主参考图比例；预览框的正方形外观不会改变最终输出尺寸。参考图中的第一个目标选区用于精确放回，其他图片作为生成参考。

## 提示词词库

词库沿用已有的 7 个公开来源，通过 [image-prompts 聚合库](https://github.com/yukkcat/image-prompts) 更新。每次打开词库时在后台检查，更新状态显示在“词库”标题后方。没有手动更新按钮，也不会在停留期间定时轮询。

先显示内置内容和上次成功缓存，清单有变化时再下载变化的来源。网络失败或数据无效时保留已有内容，收藏不会被在线更新覆盖。新增内容取决于上游实际发布和同步时间，不是秒级推送。

## 历史与费用

任务快照和结果保存在插件的数据目录中，重开 Photoshop 后可查看并复用已保存的历史。源 Photoshop 文档或图层已不存在时，需要重新准备对应素材。

多张生成可能分别计费，实际费用以服务端账单为准。停止任务会停止插件继续等待，已提交的接口请求不一定能取消。网络异常时的历史查询不会再次发送付费生成请求。

## 安装和更新

支持 Windows、Photoshop 26.9 及以上。具体步骤见 [安装与使用说明](安装与使用说明.md)。

点击插件左上角图标或版本号检查 GitHub Release；发现新版后可启动更新程序。更新前会保存已修改文档，新文档需要选择保存位置，然后正常关闭 Photoshop、替换插件并重新启动。更新需要用户主动发起。

API Key 保存在 UXP 安全存储中，发布包不包含用户账户密钥。更新使用相同插件 ID，保留现有设置、收藏和已保存历史。临时参考图和未提交提示词需要在重启前自行保留。
