# 安装与使用说明

## 首次安装

适用于 Windows 和 Photoshop 26.9 及以上版本。

1. 从 [最新 Release](https://github.com/qa963886265/x-image-photoshop/releases/latest) 下载 `x-image-photoshop-v1.10.2.zip`。
2. 将 ZIP 完整解压到固定目录。目录内应包含 `manifest.json`、`index.html`、`lib/`、`assets/` 和 `updater/`。
3. 打开 Adobe UXP Developer Tool，选择 Add Plugin，指定解压目录中的 `manifest.json`。
4. 启动 Photoshop，在 UXP Developer Tool 中点击 Load，然后打开插件面板。
5. 在插件设置中填写自己的接口账户信息，再从选区、图层或本地添加参考图开始使用。

请保留完整文件夹结构，不要只复制 HTML 或 JS 文件。

## 已有插件更新

1. 先保留当前临时参考图和未提交的提示词。
2. 点击插件左上角图标或版本号检查更新。
3. 发现新版本后启动更新。已修改文档会先保存；未保存过的新文档需要自行选择保存位置。
4. 如果 Windows 弹出权限确认，请自行完成确认。
5. 更新程序下载并校验插件版本，正常关闭 Photoshop，替换文件后重新启动 Photoshop。

取消保存或 Photoshop 未能关闭时，更新会停止。更新程序在替换期间临时备份旧插件目录；替换失败时会尝试恢复原目录，成功后清理临时备份。更新日志位于系统临时目录的 `JXImageUpdater.log`。

插件 ID 保持 `llai.psapi.selectioneditor`，因此已有安全存储、收藏和已保存历史仍使用原来的 UXP 数据目录。临时参考图和未提交提示词不会跨重启保留。

## 两种更新的区别

- **插件更新**：主动点击左上角图标或版本号启动，需要重启 Photoshop。
- **词库更新**：仅在打开词库时后台检查，失败时使用缓存；不需要重启 Photoshop。
